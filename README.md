# Aviator BET261 — Simulateur Android (projet source)

Application Android native en Java, sans compte et sans réseau.

## Fonctions
- Simulation **aléatoire et fictive** d’un multiplicateur, clairement identifiée comme telle.
- Saisie manuelle des multiplicateurs historiques.
- Statistiques descriptives, graphique des 40 dernières valeurs, historique local, annulation et effacement.
- Interface sombre et accents turquoise.

**Avertissement :** aucun résultat futur n’est prédit. Aucun accès à BET261 ni affiliation avec la plateforme.

## Construire un APK
Ouvrir ce dossier dans Android Studio (SDK 35), puis Build > Build APK(s).
Ou pousser le dossier dans un dépôt GitHub et lancer l’action `Build Android APK` ; télécharger l’artifact `AviatorBET261Simulator-debug-apk`.

Le ZIP est un projet source, pas un APK compilé.
